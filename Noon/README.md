# Noon UAE · UX heuristic evaluation

First-time buyer journey: sign up, browse, product page, add to cart, checkout attempt. Expert heuristic walkthrough of the Noon UAE desktop website (Oct 2026) using Nielsen's 10 heuristics and UX laws. Independent educational work, not affiliated with Noon.

- Deck: [`Noon_UAE_UX_Heuristic_Evaluation.pdf`](./Noon_UAE_UX_Heuristic_Evaluation.pdf) (16 pages, 8 slides plus 8 pages of screenshots)
- Claude artifact: see the portfolio page linked from the root README

## Findings (7)

| Issue | Heuristic or law |
|---|---|
| Sign-up modal cluttered by rotating icons | Aesthetic and minimalist design |
| Email OTP forces a 3-step detour | Jakob's Law |
| Product page shows 8+ competing elements | Miller's Law |
| 5.0 rating shown with no reviews | Consistency and standards |
| Cart surrounds checkout with 5 recommendations | Aesthetic and minimalist design |
| Unserviceable-address error has no path forward | Help users recover from errors |
| Modal close buttons about 24px, low contrast | Fitts's Law |
