# Klook · UX evaluation and redesign

Target flow: booking a multi-option, full-day speedboat excursion (dates, transport tiers, group size, dynamic pricing). Independent educational work, not affiliated with Klook.

- Deck: [`Klook_UX_Evaluation_Redesign.pdf`](./Klook_UX_Evaluation_Redesign.pdf) (8 slides)

## Findings (5)

| Issue | Heuristic or law |
|---|---|
| Package choice paralysis | Hick's Law; aesthetic and minimalist design |
| Micro touch targets on guest counters | Fitts's Law |
| Dead-end promo errors | Help users recover from errors |
| Chaotic pickup mapping | Visibility of system status; match with the real world |
| Intrusive upsell banner before payment | Aesthetic and minimalist design |
